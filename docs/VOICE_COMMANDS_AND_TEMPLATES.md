## ⚙️ Что здесь настраивается

Vox Bee использует три основных файла:

- `commands.json` — голосовые команды
- `aliases.json` — исправления типичных ошибок распознавания
- `scripts.json` — голосовые триггеры для пользовательских скриптов

В установленной версии они лежат в:

```text
%APPDATA%\VoxBee\
```

Открыть папку можно так:

```text
трей -> правый клик -> Команды -> Папка настроек
```

---

## ✋ Когда лучше не редактировать файлы вручную

Не редактируйте JSON-файлы, если вам нужно только:

- выбрать микрофон
- включить или выключить команды
- включить VAD
- включить `math mode`
- включить логирование
- поменять язык интерфейса

Для этого достаточно меню трея и окна настроек.

## 🧩 `commands.json`

### Что это такое

Файл с голосовыми фразами, которые запускают действие.

Если сказанная фраза совпала с триггером, Vox Bee выполняет команду.  
Если не совпала, фраза считается обычной диктовкой.

### Поддерживаемые форматы

#### Старый формат

```json
"save_file": {
  "triggers": ["сохрани", "сохранить"],
  "type": "hotkey",
  "value": "ctrl+s"
}
```

#### Новый multilingual-формат

```json
"save_file": {
  "triggers": {
    "ru": ["сохрани", "сохранить"],
    "en": ["save file"],
    "common": ["save"]
  },
  "type": "hotkey",
  "value": "ctrl+s"
}
```

### Что значат поля

- `triggers` — фразы, которые активируют команду
- `type` — тип действия
- `value` — параметр действия

### Основные типы действий

| `type` | Что делает |
|--------|------------|
| `paste` | вставляет текст |
| `hotkey` | нажимает сочетание клавиш |
| `mouse_click` | клик мышью |
| `mouse_move` | сдвиг курсора |
| `mouse_continuous` | непрерывное движение мыши |
| `mouse_stop` | остановка движения |
| `mouse_scroll` | прокрутка |
| `grid` | переход по сетке |
| `grid_zoom` | уточнение по сетке |
| `focus_switch` | переход к точке фокуса |
| `focus_save` | сохранение точки фокуса |

## 🔁 `aliases.json`

### Что это такое

Файл замен для случаев, когда Whisper стабильно слышит слово неправильно.

Пример:

```json
{
  "светка": "сетка",
  "клип": "клик"
}
```

Поддерживается и multilingual-формат:

```json
{
  "ru": {
    "светка": "сетка"
  },
  "en": {
    "copi": "copy"
  }
}
```

### Когда использовать алиасы

Используйте `aliases.json`, если ошибка влияет именно на команду или короткий триггер.

Если вы хотите исправить обычное слово в итоговом тексте, лучше использовать пользовательский словарь, а не алиас.

---

## 📄 Откуда берутся шаблоны

При первом запуске Vox Bee создаёт пользовательские файлы из шаблонов:

- `src/commands_template.json`
- `src/aliases_template.json`

Это важно для разработчиков:

- шаблоны обновляют стартовую конфигурацию для новых установок
- существующие пользовательские файлы не должны затираться

---

## 🛡️ Безопасный порядок ручного редактирования

1. Сделайте резервную копию файла.
2. Откройте JSON в редакторе с подсветкой синтаксиса.
3. Внесите изменение.
4. Сохраните файл.
5. В трее выберите `Перезагрузить команды и алиасы`.

Если после этого команды перестали работать, почти всегда проблема в синтаксисе JSON.

---

## ⚠️ Типичные ошибки

| Ошибка | Что произойдёт |
|--------|----------------|
| пропущена запятая | файл не загрузится |
| одинарные кавычки вместо двойных | файл не загрузится |
| лишняя запятая перед `}` | файл не загрузится |
| изменения сохранены, но не выполнена перезагрузка | программа продолжит работать со старой версией файла |
